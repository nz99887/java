# 登录网站（桌面版）

纯 Node.js 实现的登录网站，零依赖，无需 `npm install`。

## 快速开始
- **方式一（最简单）**：双击 `start.bat`，等待出现 `http://localhost:3000`，然后浏览器打开该地址。
- **方式二（命令行）**：
  ```bat
  cd login-site
  node server.js
  ```
  浏览器访问 http://localhost:3000

## 功能
- 注册 / 登录 / 登出
- 显示/隐藏密码、密码强度条
- 记住我（30 天会话）
- 登录失败 5 次锁定 5 分钟（防暴破）
- 账号信息面板（登录次数、注册/上次登录时间）
- 修改密码
- 暗色模式
- 受保护页面 `/dashboard`（未登录自动跳回首页）

## 说明
- 账号数据保存在 `users.json`（首次运行后为 `{}`，注册后自动写入）。
- 密码使用 scrypt 加盐哈希，全程不存明文。
- 停止服务：在运行窗口按 `Ctrl+C`。
